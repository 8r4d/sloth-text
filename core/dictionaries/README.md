# Spelling dictionaries

Used for spell checking on Windows and Linux (the Mac uses its own spell
checker). English (US) and English (UK, "-ise"), from
[wooorm/dictionaries](https://github.com/wooorm/dictionaries), which takes
them from [SCOWL](http://wordlist.aspell.net/). Their licences are beside
each word list. The two share one affix file (`en-US/en.aff`).

A word is accepted if either dictionary has it.
